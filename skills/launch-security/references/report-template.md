## Правила заполнения

- **Каждая находка — с `файл:строка` и конкретным сценарием эксплуатации.** Без сценария
  это не находка, а пересказ чек-листа.
- **Указывай способ проверки**: чтение кода / запуск / подтверждение человека. Чтение кода
  и практическая проверка — разной силы доказательства, не смешивай их.
- **Секреты только маской**: первые 8 и последние 4 символа. Отчёт попадёт в git.
- **Приоритет — по реальному эффекту**, а не по громкости названия уязвимости.
  Инфляция P1 приводит к тому, что не чинят ничего.
- Раздел «Что я смотрел» обязателен: он честно показывает, чего аудит не покрыл.
