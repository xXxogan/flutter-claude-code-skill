# Шаблон отчёта

Кладётся в `docs/launch/web-<YYYY-MM-DD>.md`. Пустые разделы удаляй, не оставляй «TBD».

```markdown
# Пред-запусковый аудит сайта — <YYYY-MM-DD>

Объект: <URL прода/стейджа> · <путь к репозиторию>
Стек: <что определено>
Проверены секции: <список> · Не проверялись: <список и почему>

Итог: ✅ N · ⚠️ N · ❌ N · 🙋 N · ⏭ N
**Запускать можно / нельзя** — одна фраза с причиной.

## P1 — блокеры запуска

### WEB-12 · robots.txt закрывает весь сайт — ❌
Факт: `curl -s https://site.ru/robots.txt` → `User-agent: *` / `Disallow: /`.
Последствие: сайт не попадёт в индекс вообще.
Что сделать: убрать `Disallow: /`, добавить строку `Sitemap: https://site.ru/sitemap.xml`.

### WEB-01 · Форма не проверена — 🙋
Факт: обработчик `src/api/contact.ts:14` отправляет через Resend, ключ `RESEND_API_KEY`
в `.env.example` есть, в прод-окружении наличие подтвердить не могу.
Что нужно от тебя: отправь тестовую заявку и скажи, дошло ли письмо.

## P2 — починить на первой неделе

| Пункт | Статус | Факт | Что сделать |
|---|---|---|---|
| WEB-22 og:image | ⚠️ | относительный путь `/og.png` в `index.html:18` | абсолютный URL, 1200×630 |

## P3 — полировка

<таблица того же вида>

## Нужно от тебя (🙋)

Конкретные запросы, по одному на строку, с указанием, что без этого не делается:
- 3–5 реальных отзывов (имя, текст, источник + ссылка) — иначе блок отзывов и разметку
  `Review` не ставим.
- Точный адрес, телефон и часы работы, как в карточке Яндекс.Бизнес — для карты и NAP.
- Реквизиты ИП/ООО с ИНН — для футера.

## Не проверено (⏭)

- WEB-42 замер скорости — нет доступа к проду, стейдж за basic auth.

## Измерения

LCP / CLS / INP на мобильном профиле, коды ответов ключевых URL, размер главной страницы.
```

## Правила заполнения

- **Факт обязателен в каждом пункте.** `файл:строка`, код ответа, кусок вывода команды.
  Пункт без факта — это ⏭, а не ✅.
- P1 и 🙋 пишутся развёрнуто, P2/P3 — таблицей: длинные объяснения к мелочи никто не читает.
- «Что сделать» — конкретное действие, а не «исправить мету».
- Ничего не выдумывать: нет данных — это 🙋 с вопросом, а не придуманное значение.
