# Шаблоны артефактов

Копируй структуру, но не тащи пустые разделы: нечего написать в раздел — удали его,
а не оставляй «TBD». Исключение — `state.md`, он всегда полный.

---

## state.md

```markdown
# Состояние пайплайна

Проект: <имя>
Обновлено: <YYYY-MM-DD>

Текущая стадия: **7 — implementation**
Ворота: пройдены до стадии 6 включительно (пользователь подтвердил 2026-07-22)

Следующее действие: T-05 «Пагинация выдачи»

## История стадий
- 0 context load — 2026-07-22
- 1 idea — 2026-07-22
- 2 plan + criteria — 2026-07-22
- 3 risk spikes — 2026-07-22 (спайк 02 изменил план: см. decisions.md)
- ...
```

## brief.md

```markdown
# Project Brief: <имя>

## Суть
3–5 предложений: что строим, для кого, какую боль снимаем, что считается успехом.

## Пользователь и сценарий
Кто запускает, как часто, откуда (CLI / расписание / другие люди).

## Скоуп
**В скоупе:** ...
**Вне скоупа (non-goals):** ...

## Стек и окружение
ЯП и версия, ключевые библиотеки (с версиями и почему они), ОС-специфика.

## Внешние зависимости
Источник данных / API: адрес, авторизация, лицензия, ToS-ограничения, что известно
о защите и лимитах.

## Ограничения и риски
Список. Каждый риск — с указанием, чем он закрыт: спайком, дизайном, или «принят как есть».

## Как запускать
Установка зависимостей, переменные окружения, команда запуска, команда тестов.
Заполняется на стадии 5 теми командами, которые реально отработали, и уточняется на 9.
Пустой раздел блокирует аудит: аудитору нечем проверять.

## Глоссарий
Термины предметной области, если они не самоочевидны.
```

## contracts.md

```markdown
# Контракты

## Модели данных
```python
@dataclass(frozen=True)
class Listing:
    id: str            # OLX-идентификатор объявления, "1234567890"
    title: str
    price: int | None  # в валюте currency; None = "договорная"
    currency: str      # ISO-4217, "UAH"
    url: str
    posted_at: datetime  # UTC, aware
```

## Публичные сигнатуры
```python
def search(query: str, filters: Filters, *, max_pages: int = 3) -> list[Listing]: ...
```

## Хранилище
Файл/БД, схема, ключ идентичности (дедуп-ключ) и почему именно он.

## Схемы ответов источника
Что реально приходит и какие поля мы берём. С примером.

## Конфигурация
| Параметр | Тип | Дефолт | Откуда | Смысл |
|---|---|---|---|---|

## Секреты и доступы
| Переменная | Что это | Где получить | Что при отсутствии |
|---|---|---|---|
| `OLX_API_KEY` | ключ к API объявлений | личный кабинет, раздел «Разработчикам» | падаем на старте |

Значения здесь не пишутся никогда. `.env` — в `.gitignore`, `.env.example` — с именами
без значений.

## Ошибки
| Исключение | Когда | Что делает вызывающая сторона |
|---|---|---|
```

## release.md

```markdown
# Выкат <YYYY-MM-DD>

Что выкачено: <версия / коммит>
Куда: <хостинг, домен, окружение>

## Пред-запусковые проверки
| Проверка | Отчёт | P1 закрыты |
|---|---|---|
| /launch-security | `docs/launch/security-2026-08-13.md` | да |
| /launch-web | `docs/launch/web-2026-08-13.md` | да, кроме WEB-17 (см. ниже) |

## Проверено после выката
Что открывали и прогоняли **на проде**, а не на локалке. Конкретными действиями:
«отправил заявку с телефона — письмо пришло за 8 секунд».

## Отложено осознанно
Пункт, приоритет, почему отложили, когда вернёмся.

## Откат
Как вернуть предыдущую версию, сколько это занимает, что при этом теряется.

## Доступы
У кого есть доступ к хостингу, домену, БД, почте, аналитике, платёжке.
Где лежат секреты. Что делать при утечке ключа.
```
